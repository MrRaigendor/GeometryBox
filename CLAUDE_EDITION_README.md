# Geometry Dash — Claude Edition

Отдельная Android-игра на Java / Android Canvas. Эта ветка не меняет основную версию Geometry Box.

## Что есть
- Два уровня: Grassland и The Nether.
- Пять игровых режимов: Cube, Ship, Ball, UFO и Wave.
- Восемь цветовых скинов.
- Редактор из 96 клеток с блоками и шипами, сохранение своего уровня и запуск теста.
- Сохранение рекорда, побед и выбранного скина на устройстве.

## Управление
- Нажатие — прыжок для Cube; касание переключает направление гравитации у Ball.
- Удержание — управление высотой Ship и Wave.
- UFO получает импульс вверх при каждом касании.
- В редакторе сначала выбери тип объекта, затем нажми на клетку.

## Сборка
Ветка `claude-edition-android` запускает GitHub Actions при каждом push. APK debug публикуется как workflow artifact после успешной сборки.
